The original cover retains its Chinese labels. They mean "central skill library," "select and sync," and "agent workspaces." A single source library supplies selected skills to multiple agent workspaces.

## The 30-second version
If you use Claude Code, Codex, and Cursor together, a skill can easily turn into three separate files. Every rule change then requires you to remember three updates.
Skills Manager collects these skills in one local central library. You choose which skills to give each agent, then sync them at global or project scope. It also supports presets, Git backups, and a CLI.
It addresses the long-term management of skills after they have been written.
## Why it is interesting
Agent skills are becoming real configuration assets. They have sources, versions, project scopes, sync states, and backup needs.
Skills Manager keeps the existing skill format and adds a management layer. The approach resembles a package manager, applied to agent behavior instructions, tool rules, and workflows.
The CRLF/LF fix in v1.39.0 makes the problem clear. When multiple computers and different agents are involved, keeping files consistent often becomes harder than writing the prompt.
## 3 designs worth borrowing
### Separate the central library from target directories
A skill enters the central library first, then syncs to each agent. Changes to the source no longer require manual maintenance of multiple copies.
### Give workspaces explicit scopes
The tool distinguishes global, project, and linked workspaces. General skills can be enabled globally, while project-specific skills stay in the project. That boundary is easier to maintain than putting every rule in one directory.
### Let users choose a sync strategy
Users can choose copies or symbolic links. Copies are more independent; links make live consistency easier. v1.39.0 also addresses false updates caused by different Windows and macOS line endings.
## How this connects to my work
If a team already maintains readable, editable skill sources in Notion and also needs to distribute the same skills to multiple coding agents, Skills Manager is better suited to local synchronization than replacing the content source. Responsibilities can be split as follows:
- Notion stores readable, editable skill sources and reference material.
- Skills needed by local coding agents are exported as standard directories.
- Skills Manager syncs those directories to Claude Code, Codex, Cursor, and other tools.
Notion continues to manage the source content, while Skills Manager handles local distribution and version consistency.
