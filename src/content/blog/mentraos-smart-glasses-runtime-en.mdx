## Understand it in 30 seconds
The most troublesome layer of building smart-glasses apps is often the different connection methods and hardware capabilities, rather than the AI model.
MentraOS puts that layer into the Mentra Runtime on the phone. Miniapps run on the phone. The runtime receives events from the glasses' microphone, camera, buttons, and other inputs, then sends display and audio output back to the device. Multiple Miniapps can share one connection.
As a result, the same Miniapp can target several supported smart glasses without rewriting the application for each piece of hardware.
## Why it is interesting
It is called an OS, but its apps do not run directly on the glasses. The official architecture puts the application runtime on the phone. The glasses handle input and output, while the phone handles app execution, permissions, and connection management.
## Design breakdown
Apps run on the phone, and the glasses handle input and output. Multiple Miniapps reuse the same runtime.
